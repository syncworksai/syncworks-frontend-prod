# SyncWorks approved branding

The PNGs are the exact user-supplied cube and full brand image. The resized icons and WebP are optimized derivatives, not replacement designs.

Recommended repository paths:
- public/brands/syncworks-approved-cube.png
- public/brands/syncworks-approved-brand-poster.png
- public/brands/syncworks-icon-192.png
- public/brands/syncworks-icon-512.png
- public/brands/syncworks-water-hero.webp

Replace /brands/syncworks-cube-s.svg references with /brands/syncworks-approved-cube.png (or optimized icon sizes) in the landing-page logo, shared ModeBar, and mobile launcher. Use the original full artwork selectively as the landing page visual/hero, e.g. background-image with background-size: cover or a dedicated side panel with object-fit: contain; add a midnight overlay to maintain text contrast. Avoid tiling the entire poster as dashboard card backgrounds. Preserve role badges and iOS safe-area.

The design files need to be added to the frontend repository for live browser URLs to resolve. Nothing in this package alters authentication or billing.
