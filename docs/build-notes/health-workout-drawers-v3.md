# Health workout drawers v3

Mobile workout interaction fix from live iPhone audit.

- Workout overlays render above Personal bottom navigation, SYNC orb, notification bubble, and coach microphone.
- Workout action dock is suppressed while an in-workout modal/drawer is open so only one interaction layer is active.
- Set-completion Save Set / Back controls remain sticky and reachable.
- Exercise media fills its card more effectively while preserving the movement focus.
- Live exercise swap drawer is mobile-safe, scrollable, compact, and sorts similar exercises first before broader catalog results.
- No backend or workout persistence changes in this build.
